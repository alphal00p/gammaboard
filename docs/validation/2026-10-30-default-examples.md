# Default examples validation — 2026-10-30

The seven cards in [the quickstart catalog](../quickstart.md#default-examples)
were created on an isolated deployment with 18 local workers. All seven root runs
and all 20 controller children completed. The dashboard's template menu contains
exactly these seven cards; support files are not listed as standalone templates.

## Native GammaLoop

The state was generated by `cargo run --example prepare_showcase` using the pinned
GammaLoop revision `227e3534a5fb39f64710b6754cc63f34ed4c95a7`. It contains the
physical gg → HHH GL15 one-loop amplitude and six native observables. The
standalone run used 32,768 training draws and 65,536 frozen-inference draws.

All four intended strata received matched samples:

| Centre | Prefix | Matches during inference |
| --- | --- | ---: |
| +1 | (0,0) | 8,462 |
| −1 | (0,1) | 2,301 |
| +i | (1,0) | 10,952 |
| −i | (1,1) | 2,459 |

For each component, the sum of stratum means and the quadrature sum of stratum
errors match the primary estimate. The real and imaginary integral observable
bins match those same estimates. The native per-stratum histogram controls,
paired estimate/error views, error reduction and JSON export were exercised in
Chromium. The external Higgs-pT bins are amplitude-weighted fixed external
kinematics, not a phase-space-integrated distribution.

These budgets validate execution and presentation, not precision. The standalone
real result was `(6.54 ± 1.61) × 10⁻⁶`, about 5.25 reported standard errors from the
upstream reference `−1.892 × 10⁻⁶`. The two campaign replicas also fluctuated
substantially. Convergence and numerical stability need larger dedicated studies;
the showcase disables rotational stability probes. Four phase strata do not
guarantee a variance reduction for this amplitude.

## Tetrahedron surface and process evaluator

Both evaluators implement `F(u,v) = (a,b,a b)` with
`a=tanh(6 cos(2πu))`, `b=tanh(6 cos(2πv))`. Their 65×65 image data agree with
`z=x*y` and the three-component Euclidean magnitude to image payload precision
(float32). Line plots contain all three components. PDF planes and lines contain
all 4,225 and 1,025 requested points and all four prefixes. The uniform process
sampler's combined PDF equals one everywhere on the unit square.

The Havana surface run used 65,536 training draws and 131,072 inference draws.
Ratios of pooled to stratified standard errors on the same draws were 2.35, 2.32
and 2.54 for x, y and z. All exact integrals are zero.

Browser checks exercised image components/magnitude, the complex x+i y projection,
PDF scope, conditional/joint/slice normalization, logarithmic density, stratum hue
with density saturation, mismatch, distributions, coverage, membership and leakage
details. Desktop and mobile layouts rendered without JavaScript errors.

## Controllers

- Tuning completed nine centre configurations: the x-coordinate of centre `(0,0)`
  takes 0.5, 1.0 or 1.5, and that of `(1,0)` takes −1.5, −1.0 or −0.5. All other
  centre coordinates, integrand definitions and sampler settings are identical
  across trials. Each child trains for 32,768 draws before 16,384 inference draws.
  The nine candidates produce distinct partitions on a 33×33 diagnostic grid.
  The original centres had the lowest reported frozen-inference x error,
  0.0034793; the other candidates ranged from 0.0035251 to 0.0035852. This is a
  comparison of reported errors at a fixed budget, not a precise determination
  of globally optimal centres. The earlier sampler-settings tuning example was
  replaced by this centre-tuning example.
- The scan completed all nine sharpness/shear points, each with a finite published
  inference-error measurement. Both controllers use integration-only children;
  plot tasks do not remain pending after the requested result is published.
  Live inspection also exposed a mean-only restriction in scan plots. Line and
  heatmap plotting now support the selected metric, including error; regression
  checks cover both mean and error data.
- The native campaign completed two replicas with distinct training and inference
  seeds, coefficients 1/2, and exactly 81,920 total draws including training.
  Combined observable means equal half the sum of child means; variances equal
  one quarter of the sum of child variances.
